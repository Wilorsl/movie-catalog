Создан каркас КиноКаталога на React + TypeScript + Vite, заменён стартовый экран, проект опубликован в Git.

Проверка:
1. `cd frontend && npm ci && npm run dev` — открывается экран «КиноКаталог».
2. Счётчика и ссылок шаблона Vite на экране нет.
3. `npm run build` завершается без ошибок.
4. `npm run preview` показывает готовую сборку.
5. Чистая копия из GitHub запускается по README.
