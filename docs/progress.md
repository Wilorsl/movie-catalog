# Прогресс

## ЛР 1 — старт проекта
Создан каркас КиноКаталога на React + TypeScript + Vite, заменён стартовый экран, проект опубликован в Git.

Проверка:
1. `cd frontend && npm ci && npm run dev` — открывается экран «КиноКаталог».
2. Счётчика и ссылок шаблона Vite на экране нет.
3. `npm run build` завершается без ошибок.
4. `npm run preview` показывает готовую сборку.
5. Чистая копия из GitHub запускается по README.

Коммит: 5b0d96f (HEAD -> main, origin/main, origin/HEAD) Lab 1: create React TypeScript app

## ЛР 2 — страницы приложения и навигация
Добавлены типизированные демонстрационные фильмы и сериалы, повторно используемые карточки и страницы каталога, подробностей, создания и 404. Навигация построена на React Router, общий layout отображается на всех страницах; неизвестный адрес и отсутствующая запись показывают разные сообщения. На экране создания указано, что форма появится в следующей работе.

Проверка:
1. `cd frontend && npm ci && npm run build` — проверка TypeScript и сборка приложения.
2. В dev-сервере открыть `/`, `/movies`, `/movies/interstellar`, `/movies/better-call-saul`, `/movies/new`, `/unknown` и `/movies/missing`.
3. Убедиться, что список показывает пять записей, карточки открываются по прямым ссылкам, а неизвестный маршрут и отсутствующая запись имеют отдельные сообщения.

Коммит: 1c9a14e (HEAD -> main) Lab 2: add media catalog pages

## ЛР 3 — формы и локальное состояние
Добавлено общее состояние каталога в `App`, создание, просмотр, редактирование и удаление записей без перезагрузки. Создание и редактирование используют общую форму с отдельным черновиком, проверкой обязательных полей, года выпуска и оценки (1–10 или не задана). В каталоге есть фильтр по статусу просмотра, сброс фильтра и отдельное пустое состояние для отсутствующих совпадений. В layout добавлено пояснение о временном хранении в памяти; README обновлён.

Проверка:
1. `cd frontend && npm run build` — проверка типов и production-сборка.
2. Проверить создание и открытие записи, редактирование и отмену, ошибки валидации, фильтр и его сброс, отмену/подтверждение удаления, пустой список, неизвестные адреса и восстановление демонстрационных данных после обновления.
3. Проверить сборку через `npm run preview`; изменения до обновления страницы сохраняются при внутренней навигации.
