# КиноКаталог

**Автор:** Репин Вячеслав Олегович 24ИС

Каталог фильмов и сериалов — семестровый проект по курсу «Лабораторный практикум».

## Основной сценарий
Пользователь добавляет фильм или сериал, ставит оценку, отмечает статус просмотра и собирает избранное.

## Стек
React, TypeScript, Vite (позже: Supabase, Node.js API)

## Версия Node
`v22.22.1`

## Запуск
Из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в `frontend`:
```bash
npm run build
npm run preview
```

## Страницы
- `/` — переход в каталог;
- `/movies` — список демонстрационных фильмов и сериалов;
- `/movies/:id` — подробности записи по её id;
- `/movies/new` — заглушка будущей формы добавления;
- любой другой адрес — страница 404.

Каталог содержит вымышленные демонстрационные записи. Данные пока хранятся в типизированном массиве; добавление и редактирование через форму появятся в следующей лабораторной.

## Зависимости
Из папки `frontend`:
Зависимости включают `react-router`; lock-файл хранится в `frontend/package-lock.json`.
