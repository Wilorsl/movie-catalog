# КиноКаталог

**Автор:** Репин Вячеслав Олегович 24ИС

Каталог фильмов и сериалов — семестровый проект по курсу «Лабораторный практикум».

## Основной сценарий
Пользователь добавляет фильм или сериал, ставит оценку, отмечает статус просмотра и собирает избранное.

## Стек
React, TypeScript, Vite (позже: Supabase, Node.js API)

## Версия Node
`v22.22.1`

## Запуск
Из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в `frontend`:
```bash
npm run build
npm run preview
```

## Страницы
- `/` — переход в каталог;
- `/movies` — каталог, фильтр по статусу просмотра и создание записи;
- `/movies/:id` — подробности записи по её id;
- `/movies/new` — создание фильма или сериала;
- `/movies/:id/edit` — редактирование записи;
- любой другой адрес — страница 404.

Можно создавать, редактировать и удалять записи, назначать им статус просмотра, оценку и отметку избранного. Фильтр по статусу применяется только к отображению каталога. Исходные данные демонстрационные; все изменения хранятся в памяти и сбрасываются после обновления страницы.

Справочник жанров загружается отдельным HTTP-запросом из `frontend/public/demo/genres.json` (`/demo/genres.json`). Форма сохраняет стабильный id жанра, а каталог и карточка показывают его название из загруженного справочника. При ошибке загрузки можно повторить запрос без потери черновика. Основные записи при этом остаются в памяти приложения.
