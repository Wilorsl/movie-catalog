# КиноКаталог

**Автор:** Репин Вячеслав Олегович 24ИС

Каталог фильмов и сериалов — семестровый проект по курсу «Лабораторный практикум».

## Основной сценарий
Пользователь добавляет фильм или сериал, ставит оценку, отмечает статус просмотра и собирает избранное.

## Стек
React, TypeScript, Vite (позже: Supabase, Node.js API)

## Версия Node
`v22.22.1`

## Запуск
Из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в `frontend`:
```bash
npm run build
npm run preview
```

## Что работает сейчас
Стартовый экран с названием, описанием и заглушкой списка. Проходят проверка типов и сборка.

## Текущие ограничения
Данных и форм пока нет: они появятся в следующих лабораторных.
